# Experiment evidence

- `swallow_timing/baseline`: original random forest results and audit.
- `swallow_timing/cnn_v1`: original pilot CNN comparison.
- `swallow_timing/grouped_cv_v1`: three-fold participant-grouped development evaluation.
- `label_review`: annotation coverage audit and unverified review queue.
- `activity/v1`: separate four-activity benchmark on STVS.

Historical metrics and plots were moved into these folders without recalculation. Older report text may refer to the original flat layout; use current setup instructions for commands. Historical code hashes describe the code used for those runs, not the reorganized package. Raw data, caches and binary weights are not checked in. Use a new output folder for each experiment.
